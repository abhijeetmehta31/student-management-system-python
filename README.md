# 🎓 Student Management System

A terminal-based Student Management System built using Python. This project allows users to manage student records through a simple command-line interface with persistent file storage.

## 🚀 Features

- ➕ Add Student
- 📋 View All Students
- 🔍 Search Student by Roll Number
- ✏️ Update Student Details
- ❌ Delete Student
- 💾 Persistent Data Storage using File Handling
- 🚫 Duplicate Roll Number Validation
- ⚠️ Exception Handling for Missing Files

## 🛠️ Technologies Used

- Python 3
- File Handling
- Functions
- Lists
- Dictionaries
- Loops
- Conditional Statements
- Exception Handling

